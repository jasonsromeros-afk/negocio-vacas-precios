# Precio del ganado en pie — Negocio Vacas

Precio de referencia por kilo (COP) que usa la app **Negocio Vacas** (Chocontá, Cundinamarca).

- `precios.json`: último promedio semanal de las principales subastas del país (Asosubastas), por categoría.
- Lo revisa Claude cada martes; si hay un reporte nuevo, actualiza el archivo y la app lo toma sola.
- No contiene ningún dato de animales, gastos ni socios.
